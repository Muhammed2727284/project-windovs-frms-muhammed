# План проекта «Учёт заказов кафе»

Windows Forms, .NET Framework 4.7.2, C# 7.3. Данные хранятся в XML-файлах (XmlSerializer).

**Как работаем:** выполняем строго по одному шагу. После шага проект собирается, затем ты проверяешь его в программе и пишешь «дальше». После этого шаг отмечается как `[x]`.

---

# Этап 1. Модели данных
Цель этапа: описать классы, в которых программа хранит блюда и заказы.

## Шаг 1.1 Папки проекта и модель блюда
- Что сделать: создать папки `Models`, `Services`, `Forms`. Создать класс `Dish` с полями Id, Название, Категория, Цена (`decimal`).
- Какие файлы создаются/меняются: `Models/Dish.cs`, `Muhammed.csproj`
- Как проверить (тест): открыть решение в VS. В обозревателе решений видна папка `Models` с файлом `Dish.cs`. Сборка (Ctrl+Shift+B) проходит без ошибок.
- [x] Статус

## Шаг 1.2 Модели заказа и статусов
- Что сделать: создать перечисление `OrderStatus` (Новый, Готовится, Готов, Оплачен). Создать класс `OrderItem` (позиция заказа: название блюда, цена, количество, сумма). Создать класс `Order`: номер, дата и время, номер стола, статус, список позиций, итоговая сумма. Название и цена копируются в позицию заказа, поэтому если потом изменить блюдо в меню, старые заказы не изменятся.
- Какие файлы создаются/меняются: `Models/OrderStatus.cs`, `Models/OrderItem.cs`, `Models/Order.cs`, `Muhammed.csproj`
- Как проверить (тест): сборка проходит без ошибок. Все 4 файла видны в папке `Models`.
- [x] Статус

Цель этапа: можно создать заказ со столом и блюдами, сумма считается автоматически.

- Как проверить (тест): форма открывается в конструкторе VS, проект собирается. Сама форма пока открывается только из следующего шага.
- [x] Статус

## Шаг 4.2 Подсчёт суммы, удаление позиции, сохранение заказа
- Что сделать: метка «Итого» пересчитывается при каждом изменении. Есть кнопка «Убрать позицию». Кнопка «Сохранить заказ» проверяет ввод: стол больше 0, в заказе есть хотя бы одна позиция, количество от 1 до 99. Новый заказ получает следующий номер, статус «Новый» и текущие дату и время, затем сохраняется в `orders.xml`. На главной форме появляется кнопка «Новый заказ».

  4. «Сохранить заказ» без позиций → сообщение об ошибке.
