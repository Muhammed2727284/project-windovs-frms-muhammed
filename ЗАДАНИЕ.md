# Задание (исходный текст)

Я делаю учебный проект для университета: приложение «Учёт заказов кафе».
Проект уже создан в этой папке: Windows Forms, .NET Framework
(не .NET Core / .NET 6+).

=== ШАГ 0. ИЗУЧИ ПРОЕКТ ===
Прочитай файлы проекта (.sln, .csproj, Form1.cs, Program.cs).
Напиши мне: версию .NET Framework, что уже есть в проекте,
и что будешь менять.

=== ТРЕБОВАНИЯ К ПРИЛОЖЕНИЮ ===
1. Меню кафе: блюда (название, категория, цена).
   Добавление, редактирование, удаление.
2. Заказы: номер стола, выбор блюд и количества,
   автоматический подсчёт итоговой суммы.
3. Статусы заказа: «Новый», «Готовится», «Готов», «Оплачен».
   Можно менять статус.
4. Главная форма: таблица заказов (DataGridView),
   фильтр по статусу, поиск по номеру стола.
5. Отчёт: выручка за день и количество заказов.
6. Сохранение данных в XML-файлы через XmlSerializer
   (без NuGet и сторонних библиотек), загрузка при запуске.

=== ТЕХНИЧЕСКИЕ ПРАВИЛА ===
- Код только совместимый с .NET Framework этого проекта.
- Формы с файлами .Designer.cs, чтобы открывались в конструкторе VS.
- Структура: папки Models (классы данных), Services (работа с файлами
  и логика), Forms (формы).
- Проверка ввода (пустые поля, неверная цена, количество) + MessageBox.
- Интерфейс и комментарии на русском языке.
- Код простой и понятный студенту, с комментариями.
- После каждого шага проект должен собираться без ошибок.

=== ПЛАН (PLAN.md) ===
Создай файл PLAN.md с планом проекта в таком виде:

# Этап N. Название этапа
Цель этапа: ...
## Шаг N.1 Название шага
- Что сделать: ...
- Какие файлы создаются/меняются: ...
- Как проверить (тест): конкретные действия в программе
  и ожидаемый результат
- [ ] Статус

Этапы должны идти от простого к сложному:
модели → сохранение в файлы → меню → заказы → главная форма →
статусы и фильтры → отчёт → финальное тестирование всех функций →
оформление (README с описанием проекта для защиты).

В последнем этапе составь таблицу тест-кейсов всех функций:
№ | Функция | Действия | Ожидаемый результат | Пройден?

4. Когда я подтверждаю шаг, отмечай его в PLAN.md как [x].
5. Если я начну новый сеанс, сначала прочитай PLAN.md

Запиши основные правила проекта в CLAUDE.md
